# 設計提案：動腦小偵探（名稱暫定）

> 給 3～6 歲小朋友的邏輯遊戲：這東西應該放哪裡？是誰的？和誰是一對？哪個不一樣？接下來是什麼？卡通風格。2026-11-06 提案，最後面「要決定的事」等家長選。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 給誰
- **3～6 歲**，在台灣，國語為主；分三個難度：3～4 歲、4～5 歲、5～6 歲。
- 不連網、不定位、沒有廣告、沒有帳號（和兄弟 APP 一樣）。

## 想練的能力
幼兒園課綱的認知領域，重點是「蒐集訊息」和「整理訊息」：觀察東西的特徵，再分類、比較、找關係。學齡前的數學和邏輯，常說的就是這幾種：

| 能力 | 意思 | 對應的遊戲 |
|---|---|---|
| **分類** | 看特徵把東西分組（水果、會飛的、紅色的） | 放哪裡？、哪個不一樣？、分一分 |
| **配對、關聯** | 找出有關係的兩樣東西（牙刷和牙膏、消防員和水管） | 是誰的？、連連看 |
| **規律和順序** | 看出重複的樣子、事情的先後 | 接下來是什麼？ |
| **推理** | 用線索一步一步刪掉不對的 | 小偵探（5～6 歲） |

研究和教學資料都說：3～4 歲多半一次用一個特徵分類（顏色、形狀、大小），慢慢才會同時看兩個特徵、看懂規律和順序。所以每個遊戲都從「一個明顯的特徵」開始，再慢慢變難。

## 主角和故事
- 小狐狸偵探**阿布**：戴小偵探帽、拿放大鏡。小鎮的大家常常東西亂放、找不到、搞混，請小朋友幫忙「破案」。
- 每個遊戲是一間「案件屋」，破一個案得到一張貼紙，貼進自己的**偵探手冊**。
- 不用認字：每一題都會念出來，畫面上只有圖。

## 五個遊戲（0.1 建議）

### 1. 放哪裡？（把東西放回家）
亂糟糟的場景，把每樣東西拖到它該去的地方。手指一碰就能拖；拖不動的小小孩也可以「先點東西、再點地方」。
- **房間**：玩具箱（球、積木、玩具車、小熊）、書架（繪本）、洗衣籃（襪子、衣服）、床（枕頭）。
- **廚房**：冰箱（牛奶、雞蛋、青菜）、碗櫃（碗、盤子）、水槽（髒杯子）。
- **浴室**：牙刷放杯子、毛巾掛架子、小鴨子放浴缸。
- **大自然**：魚放水裡、鳥放天空或鳥巢、松鼠放樹上、牛放草地、青蛙放池塘。
- **超市**（4～5 歲）：水果區、麵包區、冷凍櫃。
- **資源回收**（5～6 歲，台灣特色）：紙類、寶特瓶、鐵鋁罐、一般垃圾、廚餘。
- 難度：3～4 歲 2 個地方、很明顯；4～5 歲 3～4 個地方；5～6 歲要想原因（冰淇淋放冷凍、牛奶放冷藏）。

### 2. 是誰的？（屬於誰）
幾個人或動物排排站，頭上的泡泡是他缺的東西的虛線外框；把東西拿給對的人。
- **工作的人**：消防員—水管、醫生—聽診器、廚師—鍋鏟、警察—哨子、郵差—信、農夫—鋤頭、理髮師—剪刀。
- **動物吃什麼**：兔子—紅蘿蔔、小狗—骨頭、貓—魚、猴子—香蕉、熊貓—竹子、牛—草。
- **家人**：寶寶—奶瓶、阿公—老花眼鏡、姊姊—書包。
- **誰住哪裡**：鳥—鳥巢、蜜蜂—蜂窩、小狗—狗屋。
- **媽媽和寶寶**（5～6 歲）：母雞—小雞、牛—小牛、青蛙—蝌蚪、蝴蝶—毛毛蟲。

### 3. 連連看（和誰是一對）
左右兩排卡片，用手指畫一條線連起來（手指一碰就開始畫，和兄弟 APP 一樣）。
- **一起用的**：牙刷—牙膏、鑰匙—鎖、碗—筷子、鉛筆—紙、襪子—鞋子。
- **天氣**：下雨—雨傘、大太陽—帽子、下雪—手套。
- **為什麼**：髒手—肥皂、口渴—水、想睡覺—床。
- **從哪裡來**：牛奶—乳牛、雞蛋—母雞、蜂蜜—蜜蜂、蘋果—蘋果樹。
- 難度：2 對、3 對、4 對。

### 4. 哪個不一樣？
四張卡片，找出不一樣的那一張。
- 3～4 歲：很明顯的種類（三個水果和一台車）。
- 4～5 歲：同一類裡的特徵（三隻會飛、一隻不會）。
- 5～6 歲：要想規則（都是紅色的，但有一個不能吃）。
- 答完阿布會說出規則：「汽車不是水果。」

### 5. 接下來是什麼？（規律和順序）
- **規律**：小火車的車廂載著球和星星，AB、AAB、ABB、ABC、越來越大，最後一節空著，選下一個。
- **順序**（4～5 歲起）：蛋→小雞→母雞、種子→發芽→開花、穿襪子→穿鞋子、起床→刷牙→吃早餐。

### 以後的遊戲（0.2 起）
- **分一分**：兩三個籃子，按種類、顏色、形狀分；5～6 歲要同時看兩個特徵（紅色而且圓圓的）。
- **小偵探**（5～6 歲）：「誰拿走了蛋糕？線索 1：牠有長耳朵；線索 2：牠沒有戴帽子。」看一個線索刪掉幾個，最後找到是誰。
- **哪裡怪怪的？**：魚在樹上、大太陽撐雨傘，找出不對的地方，說說為什麼。
- **如果……會怎樣？**（因果）：冰淇淋放在太陽下會怎樣？
- **像什麼一樣**（類比）：鳥住鳥巢，那小狗住哪裡？

## 不會失敗、說出「為什麼」
- 放錯了：東西輕輕彈回去，阿布給一個關於規則的提示（「魚要住在有水的地方喔」）。錯兩次，對的地方會亮一下。不扣分、沒有倒數。
- 答對了：阿布說出**原因**（「牙刷放在浴室，因為我們在浴室刷牙。」）。小朋友聽多了，也會開始說「因為……」，這就是推理的語言。
- 自動調整難度：連續答對 3 題變難一點，錯多了就變簡單一點；家長也可以直接選年齡。

## 獎勵
- 破案得到貼紙，貼進偵探手冊；每個遊戲有 3 顆星。沒有金幣、沒有商店、沒有抽獎。

## 家長模式（要過家長關卡）
- 年齡（難度）、要玩哪些遊戲、每次玩多久（時間到了溫柔地休息，和小卡認天下一樣）、英文、聲音和語音。
- **能力進度**：分類、配對、規律、推理各答對多少，常卡住的是哪一種。
- **生活中一起玩**：收玩具時一起分類、逛超市找找水果區、出門猜猜「接下來會看到什麼」、多問一句「為什麼？」。

## 畫風：卡通（三種給家長選）
要和兄弟 APP 都不一樣：畫畫小鎮是粗框貼紙、字母寵物是水彩繪本、動物小餐廳是黏土、小卡認天下是寫實和簡單色塊。
- **A 動畫片風**（建議）：像現在的兒童卡通。細的彩色外框（不是黑色粗框）、明亮的平塗加一層簡單陰影、大眼睛、圓圓的形狀。最「卡通」，東西一眼就認得。
- **B 剪紙拼貼風**：像一層一層剪好的彩色紙，有紙的紋路和小陰影，溫暖、有手作感。
- **C 幾何積木風**：用圓形、方形、三角形拼出角色和東西，沒有外框，乾淨現代，和「動腦」很搭，但細節少，有些東西比較難認。

## 以後上架和收費（和兄弟 APP 一樣）
- 免費下載：「放哪裡？」和「連連看」的部分關卡。
- 一次買斷完整版：全部遊戲、全部場景和難度。購買只在家長模式。

## 版本計畫（建議）
- **0.1**：五個遊戲、三個難度、阿布、偵探手冊、家長模式、音樂和音效、APP 圖示。圖大約 150 張，全部用程式畫。
- **0.2**：分一分、小偵探、哪裡怪怪的。
- **0.3**：因果、類比、資源回收、更多場景、英文。

## 技術（和兄弟 APP 一樣）
- Flutter（Android 和 iOS）、Riverpod、flutter_svg、audioplayers、flutter_tts；存檔是一個 JSON 檔。
- 拖東西和畫線都用原始的手指事件（`Listener`），手指一碰就動，小朋友短短的一下也不會不見。
- 圖用 Python 畫 SVG，聲音用 numpy 合成，不用別人的素材。
