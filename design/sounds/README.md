# 想一想樂園的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，五首曲子都是為這個 APP 新寫的。

- 合成用的小工具（鐘聲、木琴、拇指琴、音樂盒、接成循環、量音量、動物聲音的共鳴方法……）是從小卡認天下的 `design/sounds/make_sounds.py` 複製過來的；烏克麗麗、大鼓、鈴鼓來自動物小餐廳，木琴（xylophone）來自字母寵物。
- 小狗、小貓、牛、羊、母雞、小鳥、猴子、青蛙，還有垃圾車的《給愛麗絲》，是從小卡認天下（它又是從畫畫小鎮）改的；蜜蜂是從畫畫小鎮的嗡嗡聲改的。
- 新做的有：旋轉木馬的風琴管、撥弦（pizzicato）、尼龍弦吉他、木笛、玻璃珠「叮」、積木敲擊、滑音笛、玩具小喇叭，五首曲子，以及其他的聲音。

給 2 歲半～5 歲的小朋友，所以**好玩、溫暖、柔和**：沒有刺耳或突然的聲音；放錯了是友善的「嗯喔～」，不是答錯的警告聲。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
```

跑完會印出每個檔案的長度、大小、最大音量、聽起來多大聲、有沒有破音、頭尾的點，還有背景音樂接頭的檢查。
- 亂數都用固定的種子，每次跑出來的檔案都一模一樣（一個 byte 都不差）。
- 程式會檢查：檔名剛好是下面這些、音效不超過 1.5 秒、角色的聲音不超過 1.2 秒、背景音樂 16～20 秒、音效頭尾都是 0。
- 全部加起來超過 4,500,000 bytes 就會停下來報錯。
- 試聽檔是每首背景音樂的前 8 秒，接著每個音效照順序播一次，中間停一下，會印出每一段從第幾秒開始。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；其他聲音 22,050 Hz。
- 背景音樂都是整數小節，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。程式用兩個方法檢查接頭：最後一個點跳回第一個點的差距（要比平常相鄰兩點的差距小），和接頭前後 0.02 秒的高音（如果有「啪」一聲會在這裡冒出來；要比曲子其他地方最響的一段小很多）。
- 其他聲音兩頭都有淡入淡出，第一個和最後一個點都是 0，不會「啪」一聲。
- **音量一樣大**：程式量每個聲音「從手機喇叭聽起來」有多大聲。
  - 怎麼量：用耳朵比較敏感的頻率（A 加權）、不算手機放不出來的低音，大約 0.2 秒一段（耳朵大約這樣把聲音加起來）。
  - 再把每個聲音調到一樣大聲（約 −21 dB）：該輕一點的就小幾 dB。例如按鈕、拿起來、放下去、「再試試」、蠟筆、小鳥、松鼠，都放得比較輕。
  - 最大音量不超過 0.72。
  - 和兄弟 APP 的音效差不多大聲。
- 背景音樂聽起來比音效輕約 8 dB（約 −29 dB；樂園地圖 −29.5 dB、休息的搖籃曲 −30 dB），放在念題目和音效下面。
- 每首曲子的旋律比伴奏響約 7～14 dB（從手機聽），旋律清楚，伴奏也聽得到。
- 手機小喇叭放不出很低的聲音。所以牛、章魚、阿布的「嗯？」、放下去的聲音這些低低的，都加了一點它自己比較高的泛音（也就是聲音裡比較高的那些成分），手機上才聽得到。
- 全部 44 個檔，加起來約 4.0 MB（4,047,946 bytes），在 4.5 MB 以內。

## 背景音樂

五首的拍子、調、樂器都不一樣，小朋友一聽就知道自己在哪裡；也和兄弟 APP 的曲子都不一樣。

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_park` | 樂園地圖 | 16.8 秒 | 旋轉木馬的華爾滋：三拍子、D 大調，輕輕的不吵。風琴管（像旋轉木馬上的那種）唱旋律，上面一支小短笛輕輕跟著；下面「嗯－恰－恰」：低音管在第一拍，短短的和弦在第二、三拍。後半首鐵琴加進來跟著唱，最後一小節往上走回開頭 |
| `music_city` | 卡通城 | 19.2 秒 | 蹦蹦跳跳的卡通曲：四拍子、降 B 大調。撥弦小提琴彈跳跳的旋律、中間常常停一下；第二遍鐵琴叮叮跟著，有兩小節烏克麗麗一起唱。下面「蹦－恰」：低音撥弦在一、三拍，烏克麗麗在二、四拍「恰」一下；小鼓、木魚、沙鈴很輕；每段結尾木魚「叩叩」，最後滑音笛「咻～」往上接回開頭 |
| `music_forest` | 紙片森林 | 18.0 秒 | 溫暖舒服：6/8 拍（搖搖的）、E 大調。尼龍弦吉他一直用手指輕輕撥；拇指琴（卡林巴）先唱旋律，接著小木笛接手，拇指琴每小節輕輕「叮」一下，每段結尾有一小串；沙鈴很輕地刷 |
| `music_blocks` | 積木王國 | 17.3 秒 | 整整齊齊、叮叮咚咚：四拍子、C 大調。木琴的旋律是一個一個小圖案（在每個和弦上同樣的形狀，像排積木）；後半首馬林巴低三度跟著唱。馬林巴低音「3＋3＋2」彈跳；積木在二、四拍「喀」一下，每個反拍有小小的木頭聲；每小節最後掉下一顆玻璃珠「叮」，每半首結尾一串 |
| `music_rest` | 休息時間 | 18.0 秒 | 很慢的搖籃曲：6/8 拍、降 E 大調，一搖一搖。音樂盒唱旋律，軟軟的鋼琴在下面低－高－低地搖；低音和溫暖的長音托著，最後鋼片琴輕輕叮兩聲 |

（三種「泡泡」各有自己的樣子，才好分辨：`say_fish` 是一串小泡泡，`say_octopus` 是兩個大的搖搖泡泡，`blub` 是好笑的「啵啵啵、啵～嗚！」。）

動物和人的聲音和兄弟 APP 一樣，是這樣做的：
- 用一個嗡嗡聲（像聲帶），通過幾個共鳴（像嘴巴的形狀），做出「哞」「咩」「喵」「謝謝」這些聲音；嘴巴的形狀可以慢慢變，例如「咿」變「耶」。
- 「謝」前面的「ㄒ」是一小段沙沙的雜音。
- 泡泡、彈簧、汽笛、煙和蠟筆，用單純的音和沙沙的雜音合成。
